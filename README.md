# muse-superpower1126c-entry

Entry for the make.fun competition [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe).

## The entry

> I can shrink any queue by one person, provided that person is me leaving it.

Candidates (3 or more) were drafted and compared against the judge brief in the competition RULES. Selection reason: the power is perfectly formed and perfectly useless - it works every time and achieves nothing, since the queue only shrinks by losing the one person who wanted it shorter; concrete, easy to picture in use, and clear in one reading.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
